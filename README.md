一个**零依赖、纯前端**的课堂点名与分组工具。整个程序（HTML + CSS + JavaScript）
全部打包在一个 `.html` 文件里，双击用浏览器打开即可运行，不需要安装、不需要服务器、
不需要联网（AI 功能除外）。

- 版本号：`27.5`（`const VERSION = '27.5'`）
- 页面标题：`📛 点名·分组工具 v27.5 · AI助手 + 反射弧 + 记忆训练`
- 文件大小：约 153 KB / 2365 行
- 兼容性：Chrome / Edge / Safari 等现代浏览器；语音点名仅 Windows 桌面浏览器可用

## 二、脱敏说明（重要）

原版 27.5 把班级真实名单**写死在网页源码里**。本副本已把下列内容**整体移除**：

| 已删除的内容 | 原位置 | 处理方式 |
| --- | --- | --- |
| 默认学生名单（49 人的姓名、性别、身份证号、权重） | 原第 826–879 行 `defaultStudents()` | 改为 `return []`，不内置任何学生数据 |
| 按真实姓名索引的成绩排名权重表 `RANKING_WEIGHTS` | 原第 880–886 行 | 改为空对象 `{}`（权重改到界面上手动调节） |
| 低权重特殊名单 `LOWEST` | 原第 887 行 | 改为空数组 `[]` |
| 4 个真实 SHA-256 口令哈希 | 原第 820–823 行 | 全部替换为占位符 `A_SHA256_value` |

替换后的代码见文件内 `/* 密码哈希常量（脱敏占位版 · 27.5 本地公开版） */` 与
`/* ---------------- 2. 默认名单与权重表（已脱敏：不含任何学生信息） ---------------- */` 两处注释。

### 关于哈希占位符 `A_SHA256_value`

`HASH_ADMIN_1`、`HASH_ADMIN_2`、`HASH_IDCARD`、`HASH_GATE` 四个常量现在都是字符串
`A_SHA256_value`。它**不是合法的 SHA-256 十六进制串**，如果照原逻辑比对，
任何口令都不可能通过 —— 总入口锁会把页面彻底锁死，甚至连试错 15 次后触发自毁。

因此脱敏版配套加入了一个判定函数：

```js
const HASH_PLACEHOLDER = 'A_SHA256_value';
function isPlaceholder(h){ return !h || h === HASH_PLACEHOLDER; }
```

含义是：**占位符 = 「该口令未配置」→ 跳过 / 放行对应的验证**。

| 常量 | 占位符状态下的行为 |
| --- | --- |
| `HASH_GATE`（总入口锁） | 打开页面时直接跳过入口锁，正常进入 |
| `HASH_ADMIN_1` / `HASH_ADMIN_2`（高级设置双层口令） | 点「🛠️ 高级设置」直接进入，不再要求输密码 |
| `HASH_IDCARD`（身份证信息解锁） | 身份证面板直接解锁显示 |

于是这个脱敏版**开箱即用**，不会被锁在门外，也适合当作模板交给别人使用。

### 如何恢复口令保护

把对应占位符换成真实口令的 SHA-256（64 位小写十六进制）。在浏览器控制台执行：

```js
crypto.subtle.digest('SHA-256', new TextEncoder().encode('你的口令'))
  .then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2,'0')).join('')));
```

把打印出来的 64 位字符串填回对应常量即可。只要四个常量里**任意一个**不再是
`A_SHA256_value`，那一项的验证就恢复为真实校验，其余仍为占位符的项继续放行
（可逐项启用，互不影响）。

## 三、首次使用：先录入名单

脱敏版打开后名单是空的，页面会提示「名单为空，请点击右上「编辑名单」添加」。
所有点名、分组、统计功能在名单为空时都会弹出提示而不是报错，可以直接操作试跑。

导入名单有三种方式：

### 方式 1：直接编辑（最简单）

点右上角「✏️ 编辑名单」→ 每行一个姓名 → 保存。
修改时会**保留已有学生的历史数据**，新增的学生默认权重 10%。

### 方式 2：从 JSON 导入 / 导出

「🛠️ 高级设置 → ⚙️ 系统 → 📥 从 JSON 导入」，粘贴完整备份 JSON（需含 `students` 数组）。
注意：导入会**替换**当前数据。
反向导出支持 **JSON / CSV / Excel** 三种格式。

### 方式 3：名单文件 roster.txt（27.5 新增，推荐）

在「🛠️ 高级设置 → ⚙️ 系统 → 📄 名单文件」中配置：

- **名单文件 URL**：留空则使用与网页同目录的 `roster.txt`
- **启动时自动拉取**：勾选后每次打开页面自动读取最新名单
- 按钮：「🔄 立即从服务器加载」「📄 导出 roster.txt」「✏️ 编辑名单文件内容」「↩️ 恢复上一次名单」

`roster.txt` 格式（空行与 `#` 开头的行会被忽略）：

```
# 2406 点名工具 · 学生名单
张三,男,330106201201011234
李四,女
王五
```

即每行支持三种写法：`姓名` / `姓名,性别` / `姓名,性别,身份证号`。
改动名单只改 txt 文件、不动源码，这也是"名单与程序分离"的安全做法。

> **注意**：用 `file://` 直接双击打开时，浏览器出于同源策略会**阻止**读取同目录的
> `roster.txt`（加载失败时会自动保留当前名单，不会清空）。要在本地使用名单文件功能，
> 请用任意静态服务器托管该目录，例如在该目录执行 `python3 -m http.server 8000`
> 后访问 `http://127.0.0.1:8000/`。若只是本地单人使用，用「方式 1 直接编辑」更方便 ——
> 数据存在浏览器 localStorage 里，下次打开仍在。

## 四、功能一览

### 1. 点名主页（🏠）

- **点名模式 / 分组模式** 一键切换
- 随机点名、**加权抽取**、可一次抽取多人（1–9 人快捷键 / 下拉选择）
- **成绩排名概率**：按 `RANKING_WEIGHTS` 与 `LOWEST` 调整各人权重（脱敏版为空，
  可在高级设置 → ⚖️ 权重面板手动调节）
- **AI 智能点名**：真正调用大模型来选人
- **撤回本抽**（`U`），误点不慌
- 统计面板：总抽取次数、每人抽中次数、历史记录
- 声音 / 彩带 / 高亮动画反馈
- 生日提醒（依据身份证号自动识别，脱敏版无数据时自动隐藏）
- 深色 / 浅色主题

### 2. AI 聊天（🤖）

- 支持 5 家服务商，**各自独立填 API Key 与选模型**：
  - DeepSeek（V3 / R1 / V4 Pro / V4 Flash / V4 Flash Vision 识图）
  - OpenRouter
  - 通义千问 Qwen（Plus / Turbo / Max）
  - 智谱 GLM（4-Flash / 4-Air / 4-Plus）
  - Moonshot Kimi（8k / 32k）
- 顶部下拉可快速切换模型
- 支持上传图片（需选识图模型）
- **AI 现场出题**：可让它按名单即时生成题目活跃课堂
- API Key 只保存在**你自己的浏览器 localStorage**，不会上传到其他地方

### 3. 反射弧（⚡）

反应速度测试小游戏，随机延迟 1000–2800 ms 后给出信号，测你的反应时间。

### 4. 记忆训练（🧠）

短时记忆小游戏，最多 20 个元素、展示 3000 ms，考察瞬时记忆。

## 九、使用建议与注意事项

1. 若要在班级实际使用，**请用原版「网页端」文件**（本脱敏版没有名单）；
   或者把真实名单单独放在 `roster.txt` 里，让源码保持干净。
2. 恢复口令保护后，请自己保管好口令 —— 忘记口令无法找回（源码里只有哈希）。
3. 浏览器清除网站数据 / 换浏览器 / 无痕模式会导致 localStorage 数据丢失，
   重要名单请用「📤 导出 JSON」定期备份。
4. AI 功能需要自行申请各服务商的 API Key，并按各家计费规则产生费用。
5. 本文件为纯静态网页，无后端、无埋点、无外部请求（AI 调用除外）。
