## 三、文件命名规则（自 2026 年起）

**程序文件一律用 `v` + 版本号 命名。**

```
✅  v27.6.html        v27.7.html        v28.html
❌  2406班点名网页本地版 27.6 公开版.html
❌  27.8.html         版本27.9.html
```

- 前缀 `v` 必须有，紧贴版本号，不加空格。
- 不在文件名里附加「公开版」「网页端」「脱敏版」等描述词 —— 版本号本身足以区分。
- 2026 年之前的历史文件保持原样，不做批量重命名。

> 完整约定见 `AGENTS.md`。

## 五、⚠️ 隐私红线

| 文件 | 敏感度 | 说明 |
| --- | --- | --- |
| `standard/网页/roster.txt` | 🔴 **高** | 含全班真实姓名与身份证号，**禁止**对外分发 |
| `standard/网页/*.html` | 🔴 **高** | 源码内嵌真实名单与真实 SHA-256 口令哈希 |
| `standard/本地/v27.6.html` | 🟢 无 | 可安全公开 |
| `standard/本地/2406班点名网页本地版 27.5.html` | 🟢 无 | 可安全公开 |

**分享 / 打包本项目之前，务必不要把 `standard/网页/` 整个目录带出去。**

发布新的公开版本时，交付前必须核对四项：

1. 全文件 **0** 个 18 位身份证号
2. 全文件 **0** 个 SHA-256 哈希值（64 位十六进制）
3. `defaultStudents()` 返回 `[]`
4. `RANKING_WEIGHTS` / `LOWEST` 为空

一行命令自查：

```bash
f=v27.6.html
grep -cE "[0-9]{17}[0-9Xx]" "$f"          # 应为 0
grep -cE "'[0-9a-f]{64}'" "$f"            # 应为 0
sed -n '/function defaultStudents/,/^}/p' "$f" | grep -c "name:"   # 应为 0
```

## 六、功能速览

- **点名主页**：随机点名 / 加权抽取 / 分组模式 / 成绩排名概率 / AI 智能点名 /
  撤回本抽 / 统计面板 / 历史记录 / 生日提醒 / 深色模式
- **📊 表格导入**（27.6 新增）：直接导入 `.xlsx` / `.csv` 名单，
  **列顺序随意**，表头颠倒、夹杂学号备注列、甚至没有表头都能识别；行顺序按文件原样保留
- **AI 聊天**：DeepSeek / OpenRouter / 通义千问 / 智谱 GLM / Moonshot Kimi，
  各自独立填 Key 与选模型，支持识图与 AI 现场出题
- **课堂小游戏**：⚡ 反射弧测试、🧠 短时记忆训练
- **数据管理**：导出 JSON / CSV / Excel，从 JSON 导入，历史快照，自动备份回滚
- **名单文件**：`roster.txt` 自动拉取，名单与源码分离

## 七、数据都存哪儿

全部存在**浏览器 localStorage**，不上传任何服务器。换浏览器 / 清除网站数据 / 无痕模式
都会导致数据丢失，重要名单请用「📤 导出 JSON」定期备份。

主要键名：`class-picker-v2-group`（主数据）、`rp_snapshots`（快照）、
`rp_prev_backup`（回滚备份）、`rp_ai_key_<服务商>`（API Key）等。

## 八、开发约定要点

- **单文件、零依赖**：不得引入 CDN / npm 包 / 外部资源，需要新能力就自己实现
  （例如 `.xlsx` 导入是自行解压 ZIP + 解析 XML 实现的）。
- 改动后必须验证：`node --check` 查语法 + 抽出被改函数在 Node 里跑单测。
- 本环境 headless Chrome 无法启动，**浏览器实跑需人工确认**。
